# Lorenzo Toccaceli — Portfolio

> **Customer Success Manager & Business Operations**  
> Multilingual Portfolio (Italiano • Español • English) with responsive design, smooth inertia scrolling, interactive physical pendulum lanyard badge, and paginated mobile experience.

---

## 🌟 Overview & Highlights

- **Role & Focus**: Customer Success Manager B2B SaaS, Client Onboarding, Retention & NRR Defense, Cross-functional Operations.
- **Multilingual Support**: Real-time browser language auto-detection and instant manual switching across **Italian**, **Spanish**, and **English**.
- **Visual Design**: Sleek dark & light theme modes, customized cyan/deep petrol palette (`#18648a`), frosted glassmorphism panels, and fluid animations.
- **Physics-based Pendulum Badge**: Interactive lanyard badge simulating physical pendulum oscillation, grab-and-drag physics, spring tension, and 3D card tilt.
- **Mobile Paginated Experience**: Optimized specifically for smartphones with section-by-section pagination, progress indicators, swipe gesture support, and quick section drawer.
- **Workflows & Automations**: Integration with **Make** and **n8n** for scalable CRM operations, automated onboarding sequences, and event tracking.

---

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations & Physics**: [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/tocca89/portfolio.git

# Enter repository directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
